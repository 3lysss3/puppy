# 爪印日记｜养宠成长记录与社区

一个使用 React + Vite + TypeScript 开发的中文可操作原型，用于记录宠物档案、健康信息和成长日常，并浏览明确标注的同城社区演示内容。

## 功能

- 宠物档案：添加或修改宠物姓名、品种、生日和所在城市。
- 健康记录：录入日期、体重、疫苗、驱虫、备注及下次提醒日期。
- 成长时间线：自动合并健康记录，并支持添加、删除养宠日常。
- 同城社区：按城市筛选预设宠友与帖子，支持发布和删除本地文字动态。
- 本地持久化：个人录入内容保存在浏览器 `localStorage` 中。
- 响应式设计：适配桌面、平板和手机浏览。
- 空状态：档案、健康记录、时间线及社区筛选均提供明确提示。

> 社区中的预设宠友和预设帖子均为虚构演示数据，并非真实用户、真实匹配或在线社区数据。个人发布内容仅保存在当前浏览器。

## 本地运行

```bash
npm install
npm run dev
```

开发服务器启动后，打开终端显示的本地地址，通常为 `http://localhost:5173`。

## 构建检查

```bash
npm run lint
npm run build
npm run preview
```

## 技术栈

- React 19
- Vite 7
- TypeScript
- Lucide React
- CSS 响应式布局

## 当前限制

- 不接后端，没有账号系统或跨设备同步。
- `localStorage` 数据只存在于当前浏览器；清除站点数据后会丢失。
- 社区不具备真实多人通信、关注、评论或匹配能力。
- 提醒日期只在页面内展示，不会发送系统通知。
- 当前只支持一个宠物档案。
